Format
Modèles 3D : assetfactory, Denys Almaral, Bard the Bowman (Sketchfab) · Three.js

Comment jouer

  • But : protéger le château. Ta base est au sud, la muraille au milieu ; les zombies sortent du brouillard au nord, par vagues. Plus ils sont grands, plus ils sont forts ; plus ils sont petits, plus ils sont rapides.
  • Ressources : les cultivateurs récoltent seuls 🪨 🪵 🪙 ⛓️ 💎. Les gisements du nord sont plus riches… et plus exposés.
  • Armée ⚔️ et Village 🌾 : la barre du bas passe d'une zone à l'autre sans interrompre la partie. Armée : caserne, champ de tir, écurie, atelier, forge, académie, dépôt (logement militaire, files de production). Village : maisons, fermes, scierie, carrière, mines, moulin, grenier, entrepôt, marché. Affecte tes villageois aux métiers : ils produisent, transportent et mangent — sans nourriture, l'armée s'affaiblit.
  • Archers : envoie-les sur la muraille (+30 % de portée, hors d'atteinte au corps à corps).
  • Formations : sélectionne plusieurs troupes puis « Former ». Ligne, Double ligne, Coin, Carré, Escarmouche, Colonne, Cavalerie en coin.
  • Siège : les armes construites vont en réserve, puis se déploient derrière la muraille (bélier : devant). Le bélier détruit les nids au nord.
  • Muraille : touche un segment pour le réparer (pierre). Une brèche laisse passer les zombies.

Contrôles

Mobile
Toucher : sélectionner / ordonner
Glisser : déplacer la vue
Appui long + glisser : sélection multiple
Deux doigts : zoom + rotation
Double-toucher : tout ce type à l'écran
Ordinateur
Clic gauche : sélectionner (glisser = cadre)
Clic droit : déplacer / attaquer
Molette : zoom · Q/E : rotation
WASD/ZQSD : caméra · Espace : pause
B : ville · G : former · X : dissoudre
